## Recording protocol

To make runs comparable, note at capture time:
- what was held fixed vs. varied (the **one** thing you changed, ideally)
- whether you edited doctrine live — live edits break controlled comparison, so for
  hypothesis tests prefer a static doctrine and let the run play out
- which hypothesis the run is meant to discriminate

A run that tests nothing is still worth keeping, but mark it `exploratory`.
